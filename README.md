# 医疗设备产品目录网站

一个基于纯 HTML、CSS 和 JavaScript 开发的医疗设备产品展示网站。该项目用于展示各类医疗设备和外科手术机器人产品，提供产品分类、筛选、详情查看和收藏功能。

## 项目结构

```
my-site/
├── index.html          # 主页面 HTML 结构
├── app.js              # JavaScript 应用逻辑
├── style.css           # 样式表
├── data.json           # 产品数据
└── assets/             # 图片资源
    ├── *.jpg, *.webp, *.png  # 产品图片
    └── .keep
```

## 主要功能

### 产品展示
- **产品模块**：展示医疗设备和外科手术机器人产品
- **技术模块**：展示相关技术信息
- **痛点模块**：展示行业挑战和需求
- **设计模块**：展示设计分析和创新

### 交互功能
- **分类筛选**：按类型过滤产品
- **标签导航**：支持 Tab 切换和子标签筛选
- **产品收藏**：点击书签图标收藏感兴趣的产品
- **详情弹窗**：点击产品卡片查看详细信息
- **图片加载失败处理**：自动回退到占位图

### 界面特性
- 响应式设计，适配不同屏幕尺寸
- 现代化的卡片式布局
- 顶部导航和锚点跳转
- 提示消息（Toast）通知
- 暗色/亮色主题支持（通过 CSS 变量）

## 使用方法

1. **本地运行**：
   ```bash
   # 使用任意静态服务器
   npx serve .
   # 或使用 Python
   python -m http.server 8000
   # 或直接用浏览器打开 index.html
   ```

2. **数据配置**：
   编辑 `data.json` 文件添加或修改产品数据

3. **添加新产品**：
   - 在 `data.json` 中添加产品条目
   - 将产品图片放入 `assets/` 目录
   - 更新对应的图片引用

## 技术栈

- **HTML5**：语义化标签结构
- **CSS3**：自定义属性、Flexbox、Grid 布局
- **JavaScript (ES6+)**：原生 JS，无框架依赖

## 浏览器支持

- Chrome / Edge (最新版本)
- Firefox (最新版本)
- Safari (最新版本)
